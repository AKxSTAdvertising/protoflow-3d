# PROTOFLOW 3D

Premium 3D sculpture, devotional art and décor e-commerce experience.

## Direction

- Next.js + React
- React Three Fiber / Three.js for immersive product viewing
- GSAP for cinematic transitions
- Sanity for products, collections and editorial content
- Vercel for deployment

## Signature interaction

A product will not jump directly to its detail page. Clicking a piece will trigger a cinematic showroom reveal: the sculpture rises from its own pedestal, moves toward the viewer, rotates, focuses, and transitions into the product detail experience.

## Development

```bash
npm install
npm run dev
```
